# 🗡️ Игра-бродилка

Проект представляет собой классический текстовый рогалик (roguelike) на фиксированное число уровней с последующим усложнением процесса игры: появлением более мощных монстров и уменьшением доступного лута.

## 🛠️ Технологии
* **Язык:** Python 3
* **Интерфейс:** `curses` (встроенная библиотека для терминальной графики)

## 📦 Установка и запуск

Проект поддерживает автоматическую локальную сборку с помощью `Makefile`. Игра запускается безопасно от имени текущего пользователя, что позволяет корректно работать системе сохранений без прав администратора (`sudo`).

### Локальная установка

1. Перейдите в папку с исходным кодом:
   ```bash
   cd single_player_game/src/
   ```
2. Создайте изолированное виртуальное окружение и установите зависимости:
   ```bash
   make install
   ```

### Запуск игры

Для запуска игры локально из папки проекта выполните команду:
```bash
make run
```

### Удаление окружения

Если вы хотите полностью удалить виртуальное окружение `.venv` и очистить проект, выполните:
```bash
make uninstall
```

## 🎮 Управление в игре

Управление персонажем и взаимодействие с интерфейсом осуществляется с помощью клавиатуры (раскладка строго английская):

### 🚶 Движение персонажа
* `w` — движение вверх
* `a` — движение влево
* `s` — движение вниз
* `d` — движение вправо

### 🎒 Инвентарь и окна выбора
* `h` — открыть окно выбора оружия
* `j` — открыть окно выбора еды
* `k` — открыть окно выбора эликсиров

### 🚪 Выход
* `q` — сохранить состояние и выйти из игры
