## 📂 Список проектов

### 1. [game_v0](./game_v0) / [game_v1](./game_v1) / [game_v2](./game_v2)
* **Стек:** Python 3, Flask, SQLAlchemy, PostgreSQL
* **Описание:** Три итерации разработки бэкенда для игры «Крестики-нолики» с поддержкой мультиплеера и игры с ботом.
* **Что внутри:** 
  * **v0:** Реализация игровой логики с использованием потокобезопасных коллекций для хранения состояния.
  * **v1:** Интеграция базы данных и добавление аутентификации пользователей (Basic Auth).
  * **v2:** Переход на безопасную аутентификацию на основе токенов (Bearer Auth).

### 2. [image_loader](./image_loader)
* **Стек:** Python 3, Asyncio
* **Описание:** Асинхронный загрузчик изображений по прямым ссылкам.
* **Что внутри:** Реализована отказоустойчивая загрузка файлов в условиях нестабильного сетевого соединения. Добавлена поддержка работы через прокси-серверы.

### 3. [simulator](./simulator)
* **Стек:** Python 3, Multiprocessing, PrettyTable
* **Описание:** Симулятор многопроцессного обмена данными в реальном времени.
* **Что внутри:** Разработан координатор, управляющий пулом независимых процессов. Каждый процесс отрабатывает заданные паттерны поведения, после чего агрегирует и выводит финальную статистику работы в консоль. Добавлен красивый вывод статуса процессов в консоль с помощью PrettyTable.

### 4. [single_player_game](./single_player_game)
* **Стек:** Python 3, PyTest
* **Описание:** Текстовая игра в жанре Roguelike («Рогалик»).
* **Что внутри:** Реализована пошаговая игровая логика с процедурным усложнением уровней (прогрессивный рост силы монстров, динамическое уменьшение доступного лута). Код полностью покрыт модульными тестами с помощью PyTest.
